## 识别中心 REC

- 概览：已开启自动识别标签 + 已停止历史入口；周期、最近扫描、人数、确认状态。删除后只读历史标明原因，不计入当前自动识别标签数。无开启标签且无历史批次才空态。
- 打开最新批次：左清单右同屏画像。初始 6 人。可移除／确认。0 命中不出现待确认。
- 李强：触发时证据 18（08:00 批次槽），当前评分 7，「当前已不满足」仅明确不命中时出现。不自动移除、不阻止确认。无提示不表示仍满足。
- 移除原因三档：当前已不满足／不应纳入本次运营人群／其他（可填说明）。不能添加患者。原始命中说明保留。
- 确认：剩余 >0 生成快照进人群列表；本范围本批次立即只读。全移除：不生成空快照，只留零人确认记录，批次只读，工作台待办消失。
- 历史批次只读，无移除／确认。新批次到来后上一批对所有范围转历史。
- 演示「产生新批次」：用当前时钟、当前规则跑 `evaluateTag` 生成新不可改写批次；失败 Toast（simulateFailure）。
- 非空最新结果一次「识别结果已更新」（工作台卡片即可）。已确认或 0 人则不出现待办。

当前复核：用**当前数据 + 当前规则**重算，仅 `not_satisfy` 提示「当前已不满足」。`unknown` / 失败不要提示为不满足。不改写历史证据。

## 人群 COH

- 列表含识别快照与主动对象；空态引导新建。
- 新建圈选：只选已发布标签纳入／排除；纳入全部命中、排除任一去掉；无且／或。缺任一标签授权不能检索。
- 主动路径**不**出现「当前已不满足」。
- 检索中移除只影响本次待保存名单。
- 存动态人群：保存条件 + **未经人工移除的完整计算结果**；0 人可存。按钮旁文案「保存条件，不保留本次人工移除」。当下即显示完整成员。无有效结果只存条件，显示尚未计算。
- 存快照：人数须 >0；0 人按钮不可用并说明。
- 动态刷新：按当前条件重算；失败 Toast，不显示 0 人名单。保留成功批次。
- 从动态确认快照：独立快照，动态仍在，移除不写回条件。
- 开放订阅按钮：有授权则跳转预填该动态人群；缺授权不能发起。
- 详情：类型、来源、纳入／排除、成员、相关批次、刷新时间。人群计算说明必须是纳入／排除组合及当时展开逻辑，**不假设唯一来源标签**。
- 从快照调整成员：以原件为起点移除，确认后生成新快照并记录来源；原件和旧交付不变；零人不生成。
- 编辑动态条件：展示关联订阅及影响；不重审、不改写旧结果。

健康活动样例操作（不要预置该人群）：纳入「成年患者」，排除「眼科复诊运营筛选」。11:00 结果为李强、林晓、吴平。

3. 健康活动圈选三人，移除李强，保存动态人群 → 当下仍三人；另存快照 → 两人。
4. 修改条件或被引用标签阈值后，旧快照来源说明仍是当时纳入／排除与展开逻辑。
5. 产生新批次后旧批次只读；新批次人数用当前规则现算（默认 11:00 为 5 人，不是写死）。
6. 删除来源标签后动态计算失效（提示原因非 0 命中），历史快照仍可读。
