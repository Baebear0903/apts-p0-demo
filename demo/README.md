# APTS P0 需求评审 Demo

虚拟数据、无真实医院库。产品行为以仓库根目录《患者标签画像服务-产品规格.md》为准。

## 启动

```bash
cd apts-p0-demo/demo
npm ci
npm run dev
```

浏览器打开终端给出的地址，通常是 `http://localhost:5173/`。

若本机 `~/.npm` 出现 EPERM：

```bash
npm install --cache "/Users/yangyinglin/AI playground/APTS演示demo/demo/.npm-cache"
```

## 检查

```bash
npm test
npm run build
```

## 演示路径

1. 系统管理 → 数据集、指标库（眼表评分）→ 标签中心编辑「眼科复诊运营筛选」→ 试算（11:00 命中 5 人，不含李强）。
2. 工作台「识别结果已更新」→ 识别中心 08:00 批次 → 李强触发 18、当前 7、「当前已不满足」→ 移除 → 确认快照。
3. 人群管理：新建「健康活动圈选」（纳入成年患者，排除眼科复诊运营筛选）→ 保存动态人群 → 开放订阅。
4. 数据开放：基于刚确认的快照新建并启用「眼科复诊名单交付」→ 授权已启用 → 直接导出 CSV。旁注不表示对方已收到数据。

侧栏底部「演示控制」默关：重置、推进时钟、模拟失败、按钮权限、规则能力样例。

部署与第三方获取代码见[仓库入口](../README.md)。生产站点使用 `#/` 路由；分享页面时保留完整地址。
