## 判断语义（必须可测）

- **直接比较**：数值 =≠>≥<≤ 闭区间；文本/枚举 =≠属于不属于；日期 =早于晚于闭区间；布尔 是/否。数值默认 ≥，其他默认 =。空值 unknown。科室不能 ≥。
- **最新值**：窗口内按业务时间取最新有效记录再比较。18→7 且阈值 ≥10 → 不命中。不能先筛异常再取最新。
- **时间窗口**：默认近 90 天相对计算时点；可固定起止（结束含全天）；事件前后偏移，天数非负。边界内命中；晚于计算时点不能作证据。
- **事件锚点**：首次/最近一次/任一次，默认最近一次；无锚点不命中；任一次逐锚点、不能拼接不同锚点证据。
- **存在/计次/零记录**：先按粒度去重再评价。存在 = 次数≥1。同次采集两行不计两次。成功无记录可为 0；失败报错。
- **最近 N 次每次满足**：先取最近 N 次**可判断**观察（跳过 unknown），正常与异常都参与排序；不足 N 不命中。
- **观察内组合**：同一 observation_id（或就诊）内且/或，再做存在/次数/最近N。跨两次观察各满足一项不能拼接。基础逻辑引用须支持逐次评价。
- **首次异常**：底座已有历史中首次满足异常的有效观察，再看是否落在窗口。不是窗口内首次。
- **较前变化**：最近两次可比有效记录。绝对=本次−前次；变化率=(本次−前次)/|前次|×100%。前次为 0 变化率 unknown；不足两次不命中。
- **连续日期**：自然日分组；每日「存在一次满足」或「全部有效观察满足」（默认前者）；缺可判断观察的日期打断，不跳日。与最近 N 次跳过无法判断观察分开。
- **衍生算术/日期差**：同患者按声明关联，禁止笛卡尔。除 0 或缺输入 unknown。日期差不取绝对值。BMI 样例 60/(1.5²)=26.67。
- **衍生窗口统计**：去重排除无效。空集合计数 0，其他统计 unknown。
